# Domino Chain Link Matching Puzzle
Connect 12 randomly drawn dominoes from a standard double-6 set into a single valid chain by matching pip values at each end.
## Features
- Visual domino tiles with pip dot layouts for all values 0–6
- Click to select a tile, then place it at the left or right end of the chain
- Valid placement enforcement — only matching pip values are accepted
- Hint button highlights all tiles that can currently be placed
- Win detection when all tiles are placed in the chain
## Usage
Click any domino tile in your hand to select it (blue highlight), then use "Place Left" or "Place Right" buttons to add it to the chain. The chain ends are shown; the selected tile must share a pip value with the chosen end.
